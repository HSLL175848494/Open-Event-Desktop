# Open Event Desktop

接入自己的信号服务器，在 HIBT 自动下单。金额可固定设置，也可按可用余额比例计算。账户余额、成交和结算记录都能在程序里查看。

当前版本 **v1.0.0**。这里只提供安装程序和 API 文档，信号服务器需要自己准备。

## 功能

| 功能 | 说明 |
| --- | --- |
| 连接服务器 | 填写域名或 IP、端口和 Token，支持 HTTP、HTTPS，可导入服务器证书 |
| 预测展示 | 查看服务器返回的价格、方向、置信度和合约周期 |
| 自动下单 | 按服务器推单下单，跳过过期或重复订单 |
| 下单金额 | 可选固定金额或可用余额比例，也可设置下单保护间隔 |
| 下单检查 | 提交前检查账户、余额、币种、周期、单笔金额及未结订单数量限制 |
| 交易限额 | 设置过去 24 小时的订单数、累计金额和净盈亏限额，达到条件后停止下新单 |
| 交易记录 | 查看当前 HIBT 账户的成交、结算和盈亏，按日、月统计 |
| 策略统计 | 查看服务器订单、胜率、收益趋势、热力图和最大回撤估算 |
| 功能测试 | 检查接口连接，或确认后提交真实测试订单 |
| 运行日志 | 记录连接状态、下单结果和异常原因 |

支持 BTC、ETH，周期包括 3、5、10、15、30、60 分钟和 1 天，能否下单以 HIBT 当时的币种、周期和金额限制为准。

## 使用步骤

1. 在“配置”中填入服务器地址、端口、协议和 Token。地址只填域名或 IP；HTTPS 服务器可按需导入公开证书。
2. 打开“HIBT登录”，登录账户，确认 UID、余额和接口凭据已就绪。Token 绑定的账号需与当前 HIBT UID 一致。
3. 选择固定金额或余额比例，设置推单有效期、下单保护间隔和交易限额，保存配置。
4. 在“功能测试”中检查连接，确认正常后，到“运行概览”开启自动下单。
5. 成交和结算在“历史记录”查看，服务器策略记录在“服务中心”查看，遇到问题可查看“运行日志”。

登录并取得有效凭据后，程序会通过 HIBT 接口下单，可以切换到其他页面。自动下单期间需保持程序运行和账户登录有效。

## 服务器接入

服务器需要实现服务器信息、Token 状态、实时预测、推单和订单历史查询接口，具体见 [API 文档](https://github.com/HSLL175848494/Event_Api)。

预测只用于展示，下单读取独立的推单接口。使用前请和服务方确认 Token 绑定的是 **HIBT UID**。

## 使用说明

- **推单有效期**：默认 15 秒，可设为 1–300 秒，过期的推单会跳过。这个设置与合约周期分开。
- **下单保护间隔**：默认 0 秒，不限制间隔。设置后，间隔内的新推单会跳过，不会等到间隔结束再补单。
- **交易限额**：订单数、累计金额或净盈亏达到设置的停止条件后，不再下新单。
- **重启**：服务器和交易参数会保存，自动下单开关会关闭，需要手动重新开启。
- **收益统计**：服务中心的收益和回撤按服务器方向验证结果估算。实际成交和盈亏看本地交易、结算记录。
- **测试下单**：会提交固定 **3 USDT 的真实订单**。确认前会列出币种、方向、周期和金额，下单前也会检查平台及账户限制。
